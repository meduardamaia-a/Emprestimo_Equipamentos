****Avaliação prática de Programação de Aplicativos****

*Projeto Empréstimo de equipamentos*

----Situação problema----
Um laboratório precisa registrar quem retirou equipamentos para atividades práticas e quantas
unidades foram emprestadas. Desenvolva uma aplicação em Python e Flet para cadastrar esses
empréstimos, consultar os registros e apresentar o total de unidades emprestadas.
Requisitos funcionais
    1. O sistema deverá permitir registrar um empréstimo com nome do responsável, equipamento e
    quantidade.
    2. O usuário deverá conseguir escolher um dos seguintes equipamentos: notebook, projetor ou
    multímetro.
    3. O sistema deverá impedir registros sem responsável ou equipamento, ou com quantidade que não
    seja um número inteiro maior que zero. Deverá informar o motivo do impedimento.
    4. Ao registrar um empréstimo válido, o sistema deverá armazená-lo e apresentar uma mensagem de
    confirmação.
    5. O usuário deverá conseguir consultar os empréstimos registrados, visualizando responsável,
    equipamento e quantidade. Os registros deverão permanecer disponíveis durante a execução do
    programa.
    6. O sistema deverá somar as quantidades de todos os empréstimos registrados e apresentar o total de
    unidades emprestadas, atualizando-o a cada novo registro.
    Escopo: não é necessário controlar estoque, disponibilidade ou devoluções. Os dados podem ser descartados ao
    fechar o programa. Não são exigidos banco de dados, autenticação, APIs ou geração de APK.

----Orientações para execução----
A avaliação é individual. Interprete os requisitos antes de iniciar. Utilize Python e Flet e escolha os
componentes e a organização da aplicação. Todas as funcionalidades deverão estar operacionais.
Desenvolva, versione, publique e entregue o projeto em até 3 horas.
Versionamento com Git e GitHub
    1. Criar um repositório Git para o projeto.
    2. Registrar pelo menos dois commits durante o desenvolvimento, com mensagens que descrevam as
    alterações realizadas.
    3. Criar um repositório no GitHub e publicar o projeto com seu histórico de commits.
    4. Entregar o link do repositório ao professor e garantir que ele consiga acessá-lo.
    Pontuação parcial: em cada critério, a nota será proporcional ao que for demonstrado. Itens incompletos ou com
    falhas receberão pontuação parcial; itens não demonstrados, zero.
